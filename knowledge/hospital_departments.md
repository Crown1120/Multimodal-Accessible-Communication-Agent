# 医院科室与服务指南

## 门诊科室分布

- 内科（一楼）：心内科、呼吸内科、消化内科、神经内科
- 外科（二楼）：普外科、骨科、泌尿外科、神经外科
- 妇产科（三楼）：产科门诊、妇科门诊
- 儿科（一楼东区）：普通儿科、儿童保健
- 急诊（一楼西侧）：24 小时接诊

## 无障碍服务

- 一楼总服务台配备手语翻译志愿者（工作日 9:00-17:00）
- 各楼层设无障碍卫生间与电梯
- 听障朋友可在服务台借用实时字幕设备
- 提供轮椅借用，凭身份证免费

## 就医流程

1. 挂号（人工窗口 / 自助机 / 线上）
2. 候诊区等待叫号
3. 诊室就诊
4. 缴费（支持医保）
5. 取药 / 检查 / 治疗

## 注意事项

本系统只提供流程、地点和公开信息，不提供诊断或处方建议。
